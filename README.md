# Lancaster Lines & Asphalt (linesasphalt.com)

Next.js 16 (App Router, Tailwind 4) rebuild of the old WordPress site. Local-SEO site for an asphalt maintenance and line striping contractor in Lancaster County, PA. 73 static pages.

```bash
npm install
npm run dev        # http://localhost:3000
npm run build && npx next start -p 3100
```

Never run `next build` while `next dev` is running on the same folder (corrupts `.next`).

## Structure

| Path | What |
| --- | --- |
| `src/lib/site.ts` | Name, phone, email, hours, nav. Single source for NAP. |
| `src/content/services.ts` | 10 service pages (copy, pricing rows, FAQs). |
| `src/content/towns.ts` | 7 legacy town pages (old URLs kept) + 14 new ones. |
| `src/content/posts/*.md` | 27 blog posts. Frontmatter is one JSON value per line. |
| `src/content/projects/*.md` | 5 project write-ups (case studies). Same frontmatter style; `photos`, `services`, `facts` are JSON arrays; `completed`/`town` may be empty when unknown. Dates and towns came from photo EXIF/GPS. |
| `src/content/images.json` | Photo manifest (generated by `scripts/process-images.mjs`). |
| `src/content/reviews.ts` | Public Google reviews shown on the old site. |
| `src/app/[slug]` | Services, legacy town pages and posts (root-level URLs, same as WordPress). |
| `src/app/service-areas/[town]` | New town pages. |
| `src/app/projects`, `src/app/projects/[slug]` | Project index and pages. Nav "Our Work" points here; /gallery/ stays as the photo wall. |
| `src/app/api/lead` | Quote form endpoint (Resend). |
| `next.config.ts` | 301 redirects from old WordPress URLs. |

## Environment variables (Vercel)

- `RESEND_API_KEY` : without it the form only logs the lead on the server and shows success.
- `LEAD_TO` : where leads go (default `contact@linesasphalt.com`).
- `LEAD_FROM` : verified sender (default Resend sandbox sender).

## Scripts

- `scripts/process-images.mjs` : source photos to `public/img/*.webp` (1600px + 640px thumbs) and `src/content/images.json`. Add a photo = add a line in that file.
- `scripts/make-og.mjs` : 1200x630 JPG social images into `public/og/`.
- `scripts/logo.mjs` : transparent logo mark from the original PNG, plus favicons.
- `scripts/icons.mjs` : client icon set to `public/icons/*.png` and the trimmed horizontal logo.
- `scripts/count-words.mjs` : refreshes `words:` in post frontmatter.
- `scripts/check-links.mjs` : crawl a running server (`BASE=http://localhost:3100`), checks links, images, titles, descriptions, canonicals, H1 count.
- `scripts/shots.mjs` : Playwright viewport screenshots (see windows tooling notes in memory).
- `scripts/convert-posts.mjs` / `extract-cities.mjs` : one-off WordPress import. **Do not re-run**, posts were edited by hand afterwards.

## Content rules

- Project write-ups: only facts visible in the photos or verified from EXIF/GPS. No stall counts, square footage or client names unless the client confirms them. 1500+ words like posts.

- Blog posts 1500+ words, plain language, no em dashes, no invented facts, testimonials or statistics.
- Prices must match the published ranges: $400 minimum; sealcoating $400 to $700 per driveway; restripe $4 to $6 per stall, new layout $8 to $12; crack filling $1 to $3 per linear foot; 1 to 3 potholes $400 to $800.
- Footer carries the dofollow Seva Web Studio credit.
